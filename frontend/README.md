# Patient Management System

## Project Description
A web-based Patient Management System developed to manage patient information and perform basic patient operations.

## Technologies Used
- React.js – Frontend
- Python FastAPI – Backend
- SQLite – Database

## Features
- Add new patients
- View all patient records
- Update patient details
- Delete patient records

## How to Run

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
pip install fastapi uvicorn sqlalchemy
uvicorn main:app --reload
```

## Purpose
Developed as part of the technical assessment to demonstrate frontend development, backend API integration, and database management skills.
